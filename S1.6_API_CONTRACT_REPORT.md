# S1.6 — API contract pipeline + frontend → backend smoke

### Verdict

PASS — воспроизводимая генерация контракта, typed client, health query и Home indicator реализованы. Повторная генерация детерминирована; 15 frontend tests, typecheck/build и реальный Vite → FastAPI smoke прошли.

### Pipeline

`FastAPI app.openapi() → frontend/openapi.json → schema.d.ts → openapi-fetch → Vue Query`

`backend/scripts/export_openapi.py` импортирует существующий app и сохраняет JSON с сортировкой ключей, indent 2, UTF-8 и завершающим newline. Output path вычисляется от repository root через путь самого скрипта; HTTP server и PostgreSQL не нужны. Ручных API definitions в exporter нет.

### Generated contract

- Generation command из `frontend/`: `npm run api:generate`.
- Script выполняет `uv run --locked --directory ../backend python scripts/export_openapi.py`, затем штатный `openapi-typescript`.
- Export: `frontend/openapi.json`.
- Generated types: `frontend/src/api/generated/schema.d.ts`; вручную не редактировались.
- Paths: `/api/health`, `/api/ready`.
- HTTP 200 обоих endpoints описан `HealthResponse`; readiness HTTP 503 — `ErrorResponse`.
- Deterministic second generation: **PASS**. Команда выполнена ровно два раза. `git diff --exit-code -- openapi.json src/api/generated/schema.d.ts` прошёл; поскольку файлы untracked, дополнительно подтверждено совпадение SHA-256 обоих файлов после первого и второго запусков (`generated-first.sha256`, `determinism.log`).

### Frontend integration

- `api/client.ts`: `openapi-fetch` client с generated `paths`, base URL `''`; browser обращается к текущему origin.
- Vite proxy `/api` → `http://127.0.0.1:8000`; backend CORS не добавлен.
- `api/health.ts`: typed `GET /api/health` и одна Vue Query. HTTP failure/missing data приводят к ошибке query; network failure также отображается как недоступность. Retries и refetch on window focus отключены; polling отсутствует.
- HomeView отображает loading, available и unavailable через безопасные сообщения в status block; внутренние error details не выводятся.
- Существующие shell/router tests адаптированы к Vue Query provider и mock на уровне openapi client. Настоящий backend в Vitest не использовался.
- README содержит generation command и development запуск в двух терминалах с объяснением Vite proxy.
