# S1.7 — Docker Compose + production single-app build/serving

## Verdict

**PASS**. Docker image собран; обязательные PostgreSQL migration, HTTP, reference data,
persistence и app restart smoke выполнены. Контейнеры остановлены, volume сохранён.

## Production architecture

```text
app
├── FastAPI /api
└── Vue SPA

postgres
└── persistent volume
```

Один app обслуживает API и SPA на одном origin. Vite development workflow сохранён.
SPA serving включается через `VESHICHKIN_STATIC_DIR`; его routes отсутствуют в OpenAPI.
Неизвестные API routes и отсутствующие assets возвращают 404.

## Image

- `frontend-build`: Node 22 Alpine, `npm ci`, `npm run build`; используется существующий generated contract.
- `backend-build`: Python 3.12, uv 0.11.25, `uv sync --locked --no-dev --no-editable` по `backend/uv.lock`.
- `runtime`: Python 3.12 slim, установленный backend и Alembic migrations, SPA в `/app/static`.
- Runtime inspection: Alembic и uvicorn присутствуют; pytest, Ruff, mypy, Node и frontend toolchain отсутствуют.
- CMD запускает `docker/start.sh`: `set -eu`, `alembic upgrade head`, затем `exec uvicorn` на `0.0.0.0:8000`, без reload.
- Жёсткого migration ENTRYPOINT нет; one-off Alembic commands проверены.
