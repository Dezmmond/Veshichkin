# S2.1 — Non-destructive item removal schema foundation

## Verdict

PASS. Добавлена минимальная persistence-семантика выбытия вещи; обязательные targeted и offline проверки пройдены.

## Schema change

`items.is_active BOOLEAN NOT NULL DEFAULT TRUE`.

ORM: `Mapped[bool]`, Python insert default `True`, server default `true`, `nullable=False`.
`true` означает принадлежность текущему каталогу, `false` — сохранённую в БД вещь вне текущего каталога. Фильтрация будет реализована последующей задачей.
Добавление поля с постоянным server default задаёт `true` существующим строкам.
Остальные constraints и семантика quantity сохранены: individual → 1, grouped → ≥ 0.
Отдельный boolean index не добавлен.
