# S1.5 — Vue/Vite application shell + routing/UI foundation

### Verdict

PASS — frontend shell, Router, Vue Query и PrimeVue foundation реализованы. 7 targeted tests, typecheck, production build и краткий dev startup прошли.

### Implemented

- `App` → `AppLayout` с navigation и `RouterView`; один главный content region и ссылка перехода к содержимому.
- Vue Router с browser history; четыре маршрута, включая fallback.
- Mobile-first верхняя навигация: «Главная», «Каталог», «Ревизия». Flex-wrap предотвращает переполнение списка; touch target — минимум 2,75rem. Текущий маршрут выделяется фоном, начертанием и подчёркиванием; RouterLink выставляет `aria-current`.
- Один небольшой global stylesheet: viewport уже настроен bootstrap; ограничена ширина контента, задан перенос текста, отступы и keyboard focus.
- PrimeVue подключён через plugin в официальном `unstyled` mode. Theme package и дополнительные UI components не потребовались.
- `VueQueryPlugin` подключён в application bootstrap. Queries не создаются, backend не вызывается.
- Views содержат только русскоязычные заголовки/placeholder messages. Not Found содержит ссылку возврата на главную.
- Vitest настроен на установленный `jsdom`; `test` остаётся non-watch (`vitest run`).
