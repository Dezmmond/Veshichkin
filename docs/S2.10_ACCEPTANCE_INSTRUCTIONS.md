# S2.10 — исправленная acceptance-команда backend tests

Stage 2 принят по успешному ручному прогону. Для последующих acceptance-прогонов использовать следующую команду из `backend/`:

```bash
export VESHICHKIN_TEST_DATABASE_URL="postgresql+psycopg://veshichkin:veshichkin_dev_only@127.0.0.1:55411/s210_quality"
export UV_CACHE_DIR="${s210_dir:?Задайте каталог временного acceptance-прогона}/uv-cache"
timeout --foreground 180s uv run pytest
```

URL должен указывать на отдельную disposable quality DB текущего временного Compose project; порт в примере — 55411 из ручного сценария. Не использовать production DB для test suite. PostgreSQL должен быть healthy, quality DB создана заранее. Ожидается 454/454 tests без skipped PostgreSQL integration tests.

`--foreground` необходим для запуска под интерактивным TTY: обычный `timeout` может выделить отдельную process group, и импорт `readline/libedit` остановит Python через `SIGTTOU`. Причина подтверждена пользователем через `faulthandler` и `strace`; с исправленной командой ручной прогон PASS. Это дефект acceptance-команды, а не приложения. При timeout зафиксировать TIMEOUT и остановить оставшиеся процессы; автоматически не повторять.
