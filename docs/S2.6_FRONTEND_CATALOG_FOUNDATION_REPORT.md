## Routes

| Route | Purpose | Status |
| --- | --- | --- |
| `/catalog` | Вход в каталог: корневые категории | PASS |
| `/catalog/categories/:categoryId` | Breadcrumb, текущая категория, непосредственные children и вещи | PASS |

ID проверяется как положительный safe integer. Некорректный параметр показывает «Категория не найдена» без API requests. Неизвестный корректный ID показывает тот же экран со ссылкой возврата после загрузки дерева, без item/reference requests.

## API layer

- `categories.ts`: GET `/api/categories`, `useCategoriesQuery()`, key `['categories']`.
- `referenceData.ts`: отдельные GET и Vue Query hooks для purposes, conditions, climates; keys `['reference', 'purposes']`, `['reference', 'conditions']`, `['reference', 'climates']`.
- `items.ts`: GET `/api/items`, generated typed filters, `useItemsQuery()`, key `['items', filters]`.
- Все requests используют существующий `apiClient` / openapi-fetch. DTO и filters взяты из generated contract; ручных DTO interfaces нет. Polling, global store и manual cache отсутствуют.
- Item/reference queries включаются после нахождения категории. Reactive filters и query key обновляются при смене route ID.

## Category navigation

Корни и непосредственные children выводятся в исходном backend порядке. Pure helpers находят категорию и путь root → leaf в полном дереве. Breadcrumb строится без отдельного request, содержит ссылку на каталог и ссылки всех ancestors. Seeded category names не hardcoded. Ссылки имеют touch target минимум 44px, длинные названия и breadcrumb переносятся.

## Catalog list

GET `/api/items?category_id=<id>` запрашивает точную категорию; descendants не подмешиваются, локальной фильтрации `is_active` нет. Карточки показывают name, русское представление tracking_mode, quantity, condition, purposes, climates и заполненные brand/model/color/size/material. Reference names получаются из трёх API queries через computed maps; ID не служат пользовательскими labels. Grouped quantity явно видна.

Есть loading, безопасные error и empty states для root/category/list. Отсутствие children не создаёт пустой section. Неуказанные references имеют текстовые значения. Карточки без click action и dead links. CSS добавлен только для каталога, без global redesign.
