# S1.2 — Backend foundation

### Verdict

PASS — runtime foundation реализован; 10 targeted tests, Ruff, mypy и import прошли. Проверки выполнены 2026-10-01.

### Implemented

- FastAPI entrypoint с `/api` prefix и feature-пакетом `health`.
- `pydantic-settings`: application name, environment, debug, PostgreSQL DSN; prefix `VESHICHKIN_`. Default — localhost DSN без пароля; допустим только `postgresql+psycopg`.
- SQLAlchemy 2 sync engine, Psycopg 3, `sessionmaker`, явная Session dependency с закрытием через context manager. Engine освобождается при shutdown; import/startup не подключается к БД.
- Liveness без БД; readiness выполняет `SELECT 1`, при SQLAlchemy-ошибке возвращает безопасный HTTP 503. Connection timeout и pool timeout — по 3 секунды; retry framework отсутствует.
- Один `ApplicationError` и handler с JSON форматом `error.code` / `error.message`; произвольные исключения не перехватываются.
- Добавлены runtime dependency `uvicorn` и test dependency `httpx`; обновлён `uv.lock`. Backend development section README содержит setup и runtime contract.

### Runtime contract

- App import path: `veshichkin.main:app`.
- Python: 3.12 или 3.13.
- Установка из корня: `uv sync --locked --directory backend`.
- Запуск из корня: `uv run --directory backend uvicorn veshichkin.main:app --reload`.
- `GET /api/health`: HTTP 200, `{"status":"ok"}`, без обращения к PostgreSQL.
- `GET /api/ready`: HTTP 200, `{"status":"ok"}` при рабочей БД; иначе HTTP 503, `{"error":{"code":"database_unavailable","message":"Database is unavailable"}}`.
- Database env variable: `VESHICHKIN_DATABASE_URL`.
- Default: `postgresql+psycopg://veshichkin@localhost:5432/veshichkin`. PostgreSQL предоставляется отдельно; при необходимости credentials задаются через environment.
