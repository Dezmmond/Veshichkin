### Schema implemented

| Table | Purpose | Important constraints |
| --- | --- | --- |
| `categories` | Иерархия категорий и последняя завершённая проверка | BigInteger Identity PK; self-FK RESTRICT; parent != id; sort_order >= 0; state empty/nonempty/NULL |
| `purposes` | Справочник назначений | SmallInteger Identity PK; unique code/name; sort_order >= 0 |
| `conditions` | Единая шкала состояния | SmallInteger Identity PK; unique code/name/rank; rank >= 0 |
| `climates` | Справочник климатов | SmallInteger Identity PK; unique code/name; sort_order >= 0 |
| `items` | Individual/grouped catalog item и характеристики | BigInteger Identity PK; category NOT NULL; category/condition FK RESTRICT; допустимый tracking_mode; individual quantity = 1, grouped quantity >= 0; JSONB NOT NULL default `{}` |
| `item_purposes` | Связь item ↔ purpose | Composite PK; item FK CASCADE; purpose FK RESTRICT |
| `item_climates` | Связь item ↔ climate | Composite PK; item FK CASCADE; climate FK RESTRICT |
| `measurement_profile` | Один профиль замеров | SmallInteger PK без Identity; CHECK id = 1; nullable Numeric(6,2) measurements > 0; JSONB NOT NULL default `{}` |
| `revision_sessions` | Сессия ревизии | BigInteger Identity PK; status in_progress/completed/cancelled; completed_at >= started_at, если задано |
| `revision_category_results` | Progress и результат категории в ревизии | Composite PK; session FK CASCADE; category FK RESTRICT; status pending/in_progress/completed/skipped; result empty/nonempty/NULL; completed требует result_state и verified_at |

Всего 21 CHECK и 9 FK. Обязательные поля — NOT NULL. PK/FK/UNIQUE/CHECK/index names формируются стабильным naming convention; длинное FK-имя PostgreSQL сокращается SQLAlchemy детерминированно. Добавлены индексы для FK, которые не покрыты первым столбцом composite PK.

Timestamps — timezone-aware PostgreSQL. created_at/updated_at/started_at имеют server-side `now()` defaults; updated_at также обновляется SQLAlchemy при ORM UPDATE. Отдельные audit subsystem и DB triggers не добавлены. Singleton constraint допускает отсутствие профиля до заполнения данными.
